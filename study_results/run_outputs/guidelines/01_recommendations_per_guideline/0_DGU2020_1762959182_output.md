Based on the S3 guideline for penile cancer, the explicit treatment recommendations are as follows:

| Aspect of Care | Recommendation |
| :--- | :--- |
| **Diagnosis & Staging** | For unclear penile lesions, early histological diagnosis should be obtained. |
| | For primary staging, cross-sectional and hybrid imaging methods should only be used for T3/T4 tumors or in cases of positive lymph node status. |
| | For superficial, non-invasive penile carcinomas (Carcinoma in situ), a fluorescence-diagnostic technique can be used to better determine the extent of the lesion. |
| **Treatment of Primary Tumor (General)** | Patients with penile cancer should receive organ-preserving therapy depending on the tumor stage and differentiation grade. |
| | Treatment of superficial and non-invasive penile carcinomas should only be performed after a conclusive histological diagnosis has been established. |
| **Treatment of Primary Tumor (Non-Invasive/Superficial: PeIN, Tis, Ta, Precancerous)** | For superficial, non-invasive penile carcinomas, an organ- and function-preserving curative treatment should be pursued. |
| | **Topical Therapy:** Therapy with 5-fluorouracil or imiquimod can be used. Patients must be informed about limited efficacy and off-label use. This treatment should not be repeated after failure. |
| | **Laser Therapy:** CO2 laser can be used for penile intraepithelial neoplasia (PeIN) and precancerous lesions. Nd:YAG laser with deep coagulation can be used for Ta/T1 tumors. |
| | **Control Biopsy:** After topical medical therapy or laser therapy, a control biopsy must be performed to verify local tumor control. |
| | **Glansectomy:** Complete surgical de-epithelialization of the glans ("glans resurfacing") can be used for Carcinoma in situ (CIS). |
| **Treatment of Primary Tumor (Invasive: T1-T4)** | **Tumors confined to prepuce:** Should be treated by circumcision. |
| | **Small T1/T2 tumors of the glans:** Local excision should be performed. The non-diseased prepuce can be preserved. |
| | **T1/T2 tumors:** Glansectomy should be offered, depending on tumor location and extent. If glansectomy is not possible and surgery is desired, a partial penectomy should be performed. |
| | **T1/T2 tumors (Non-surgical):** Local radiotherapy can be performed as an organ-sparing therapy. Patients must be informed that percutaneous radiotherapy has a lower local control rate than surgery. When using radiotherapy or topical therapy, a circumcision should be performed. |
| | **T3 tumors (invasion of corpora cavernosa):** A partial penectomy should be performed. For extensive tumors, a radical penectomy may be necessary. Alternatively, local radiotherapy (preferably brachytherapy) can be performed, though local control is lower than with penectomy. |
| | **T4 tumors:** An extensive surgical resection or local radiotherapy should be performed. Neoadjuvant chemotherapy or radio-chemotherapy should be considered. |
| | **Surgical Margins:** For organ-sparing surgery, the margin should be at least 1-few millimeters. In case of a positive surgical margin, a re-excision should be performed. |
| **Treatment of Local Recurrence** | **After organ-sparing surgery:** Recurrence should be treated according to the same principles as primary tumors. |
| | **After radiotherapy:** Recurrence should be treated with surgical salvage therapy. |
| | **After topical or laser therapy:** Recurrence should be treated with a different treatment modality. |
| **Lymph Node Management (Clinically Negative Nodes, cN0)** | **Low-risk (pTa and pT1aG1):** Operative lymph node staging can be omitted in favor of clinical surveillance only. |
| | **Intermediate/High-risk (≥pT1b):** Clinically non-palpable inguinal lymph nodes should be invasively staged via either dynamic sentinel lymph node biopsy (DSNB) or modified inguinal lymphadenectomy. |
| | **Intraoperative Management (for cN0):** Frozen section analysis should not be performed on tissue from a modified inguinal lymphadenectomy or DSNB. |
| **Lymph Node Management (Clinically Positive Nodes, cN1/cN2/cN3)** | **Palpable nodes (cN1/cN2):** Palpably enlarged inguinal lymph nodes should be histologically confirmed by operative removal. If metastasis is proven, a radical inguinal lymphadenectomy should be performed. |
| | **Fixed nodes (cN3) with good performance status (ECOG < 2):** Neoadjuvant chemotherapy should be administered. |
| | **Primarily resectable fixed nodes:** Neoadjuvant chemotherapy should be offered to reduce tumor burden and postoperative morbidity. |
| | **Intraoperative Management (for cN+):** If intraoperatively suspicious nodes are removed, frozen section analysis should be performed. If positive, an ipsilateral radical lymphadenectomy should be performed in the same session. |
| | **Pelvic Lymphadenectomy:** Ipsilateral pelvic lymph node dissection should be performed in patients with ≥2 involved inguinal lymph nodes or with extracapsular extension in at least one lymph node. |
| **Systemic Therapy (Adjuvant)** | **pN1:** Adjuvant chemotherapy can be considered for patients with an aggressive tumor (≥ G2) and/or a large metastasis (≥ 3 cm). |
| | **pN2/pN3:** Adjuvant chemotherapy can be administered. |
| | **Adjuvant Regimens:** The recommended regimen is 4 cycles of Cisplatin/Paclitaxel/5-Fluorouracil. Alternatively, 4 cycles of Cisplatin/Ifosfamide/Paclitaxel can be used. |
| **Systemic Therapy (Neoadjuvant)** | **Regimens:** Recommended polychemotherapy regimens are Paclitaxel/Ifosfamide/Cisplatin (TIP) or Cisplatin/Paclitaxel/5-Fluorouracil (TPF). |
| | **Consolidation:** If neoadjuvant chemotherapy leads to a response, surgery should be performed after a maximum of 4 cycles. |
| **Management of Metastatic Disease** | **General Principle:** Patients with metastatic disease or requiring multimodal therapy should be discussed in an interdisciplinary tumor board. |
| | **First-Line Chemotherapy:** In patients with good performance status (ECOG < 2), combination chemotherapy should be administered. It should be cisplatin-based if comorbidities allow. The recommended regimen is Cisplatin/Ifosfamide/Paclitaxel. Alternatively, Cisplatin/5-Fluorouracil can be used. Bleomycin-containing regimens should not be used. |
| | **Second-Line Chemotherapy:** Paclitaxel can be used as monotherapy. |
| **Management of Recurrent/Progressive Disease** | **Regional lymph node recurrence after surveillance:** Should be treated according to the same principles as primary lymph node metastases. |
| | **Regional lymph node recurrence after radical lymphadenectomy:** Should be treated with neoadjuvant chemotherapy and surgery after histological confirmation. |
| | **Regional lymph node recurrence after false-negative staging:** Should be histologically confirmed and treated with surgery, plus neoadjuvant or adjuvant therapy. |
| **Adjuvant & Palliative Radiotherapy** | Adjuvant radiotherapy after lymph node dissection cannot be generally recommended but can be considered for patients at high risk of recurrence (e.g., high number of metastases, extracapsular extension). |
| **Supportive & Palliative Care** | For chronic lymphedema, a complex decongestive therapy (lymphatic drainage, compression therapy, and skin care) should be performed. |
| **Follow-up Care** | **General:** Regular, risk-stratified follow-up should be performed to detect recurrences and functional disorders. Patients should be taught self-examination for early detection. |
| | **Follow-up for Primary Tumor (Clinical Exam):** For organ preservation, every 3 months for years 1-2, then every 6 months for years 3-5. For total penectomy, every 3 months for years 1-2, then annually for years 3-5. |
| | **Follow-up for Inguinal Lymph Nodes (Clinical Exam +/- Imaging):** For pNx or pN1, every 3 months for years 1-2, then every 6 months for years 3-5 (optional imaging for pN1). For pN0, every 3 months for years 1-2, then annually for years 3-5. |
